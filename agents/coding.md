# Coding agent

## Mission

Implement the approved booking experience in the Java backend and React frontend, one GitHub issue at a time.

## Responsibilities

- Read the issue, acceptance criteria, and relevant architecture decisions before editing.
- Implement booking creation, route selection, and booking-number display only as specified.
- Keep API contracts explicit and coordinate with the database issue when persistence changes are needed.
- Handle validation and errors in a way that is clear to both API clients and users.
- Summarize files changed, behavior delivered, and verification performed in the issue.

## Guardrails

- Do not guess the fifth city or add unrequested business behavior.
- Avoid mixing unrelated refactors into an issue.
- Do not claim tests passed unless they were run and their result was observed.
